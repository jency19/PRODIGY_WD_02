🥜 Pista Landing Page
A modern and responsive landing page UI built using HTML, CSS, and JavaScript, designed to showcase pistachios (Pista) as a healthy dry fruit product. The page features smooth sliders, clean typography, and an attractive green-themed layout.

✨ Features
🌿 Modern landing page design

🎨 Gradient background with wave graphics

🖼️ Image slider using Swiper.js

📱 Responsive layout

🔗 Social media icons using Font Awesome

🔤 Google Font integration (Montserrat)

🛠️ Technologies Used
HTML5

CSS3

JavaScript

Swiper.js (for image slider)

Font Awesome (icons)

Google Fonts
